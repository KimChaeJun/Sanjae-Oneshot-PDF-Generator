# 산재원샷 서비스 체험 제너레이터

공개 주소: https://kimchaejun.github.io/Sanjae-Oneshot-PDF-Generator/

소개 페이지의 **서비스 체험** → 정보 입력 또는 내국인/외국인 페르소나 → 사고 유형 → 준비 서류 생성 → **체험하기** 순서로 진행합니다.

## 현재 시연 흐름

- GitHub Pages는 `static/index.html` 및 지정된 정적 자산만 배포합니다.
- 운영 API `https://sanjae-oneshot.co.kr/api/v1/demo`에 고정 연결됩니다. 별도 환경 변수나 API 키 입력이 없습니다.
- 생년월일은 년·월·일로 나눠 입력합니다. 등록번호는 앞 6자리와 뒷 첫 숫자 규칙을 맞추고 나머지 6자리를 무작위 생성합니다. JSON에는 전체 합성 번호를, 화면/PDF에는 마스킹 값을 사용합니다. 실제 발급/본인 인증용 번호가 아닙니다.
- 이름 기반 투명 PNG 서명, 단계별 `시연_입력_가이드.json`, 입력용 증빙 PDF 3종을 준비합니다. **웹 시연은 ZIP을 생성하거나 다운로드하지 않습니다.** 최종 신청서·재해경위서는 산재원샷에서 만듭니다.
- 자료는 운영 DB의 비공개 영역에 암호화해 임시 보관합니다. 최종 문서 저장 성공 시 임시 원본을 제거하고, 미완료 자료는 24시간 만료 후 정리합니다.
- 30분 유효 일회용 링크로 별도 시연 계정에 로그인합니다. 로그인 비밀번호/토큰은 가이드에 포함하지 않습니다.
- 서비스에서 입력·서명·증빙 업로드가 화면에 보이게 자동 진행됩니다. AI 보완·최종 확인은 사용자가 직접 합니다. 합성 시연 자료는 실제 제출하지 마세요.

## 저장소 구성

- `static/`: 공개 웹 UI. `demo.mjs`가 현재 진입점입니다.
- `.github/workflows/pages.yml`: 공개 자산만 Pages에 배포.
- `app/`: 기존 Python 합성 케이스·PDF 템플릿과 로컬 도구. 과거 `/api/generate` ZIP API는 호환용으로 남아 있지만 현재 공개 UI에서 사용하지 않습니다.
- 운영 실행 모듈은 메인 서비스 저장소 `backend/app/demo_generator`에 선별 동기화됩니다. `Sa-p`에서 `node scripts/sync-demo-generator.mjs`로 갱신합니다.
- `tests/`: 등록번호, 페르소나, 기존 로컬 도구 회귀 검사.

## 로컬 UI 확인

`static` 디렉터리를 정적 HTTP 서버로 열면 됩니다. 로컬에서 열어도 **운영 API에 연결**되므로 생성 버튼은 실제 임시 DB 저장과 시연 계정 생성을 수행합니다.

지원 사고 유형: 업무상 사고 / 출퇴근 / 제3자 / 업무상 질병 / 유족 / 재요양. 유형별 120개 합성 케이스입니다.

실제 개인정보, 다운로드한 JSON, 계정 정보, `.env`, 생성 파일은 커밋하지 않습니다. 실제 시연 테스트와 녹화는 자동 배포에 포함하지 않습니다.
