생년월일

이름 기반 합성 서명과 등록번호가 자동 생성됩니다.

시연용 주민번호 뒷자리는 랜덤하게 생성됩니다.

등록번호 첫 숫자만 출생 연도·성별·내외국인 규칙을 적용합니다. 전체 합성 번호는 JSON에 보관되며 실제 발급 번호나 본인 인증용이 아닙니다.

02 · 사고 유형 선택

ZIP은 생성하지 않습니다. 증빙 PDF·서명 PNG·입력 가이드를 운영 DB에 암호화해 임시 보관합니다. 최종 신청서·재해경위서는 산재원샷에서 생성합니다.
